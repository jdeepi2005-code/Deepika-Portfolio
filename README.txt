# Deepika J - Personal Portfolio

A responsive personal portfolio website created using HTML, CSS and JavaScript.

## Sections
- About Me
- Skills
- Projects Showcase
- Industry Training
- Contact Form

## Run
Open `index.html` in a browser.

## Technologies
HTML5, CSS3, JavaScript

## AI-Assisted Activity
This portfolio layout can be described as an AI-generated responsive design concept. AI was also used to improve mobile navigation, responsive grids, spacing, and form interaction.

## Note
The contact form uses `mailto:` and opens the visitor's default email application. A backend is not required for this assignment.
